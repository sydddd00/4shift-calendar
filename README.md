# 4조 교대 근무표

4조가 1주씩 돌아가는 교대 근무표를 아이폰·안드로이드·PC에서 함께 보는 웹앱입니다.
빌드 도구 없이 순수 HTML/CSS/JS로 만들어져 GitHub Pages에서 바로 열립니다.

**앱 열기 →** https://sydddd00.github.io/4shift-calendar/

## 무엇이 되나요

- **4조 × 1주 순환 자동 계산** — `오전(06:00~14:00) → 오후(14:00~22:00) → 야간(22:00~06:00) → 휴무` 순서로 매주 조가 한 칸씩 넘어갑니다. 기준 주에 각 조가 어떤 근무였는지만 한 번 정하면 그 전·후 모든 주가 자동으로 채워집니다.
- **시프트별 근무 요일** — 오전주·오후주·야간주마다 근무 요일을 따로 정할 수 있습니다. 예: 오전주는 월~금(5일), 오후주는 월~토(6일), 야간주는 7일, 휴무주는 7일 내내 휴무. 요일을 하나씩 체크하거나 `5일 / 6일 / 7일` 버튼으로 바로 맞출 수 있습니다.
- **조 이름 바꾸기** — 1조·2조 대신 "나", 친구 이름 등으로 바꿔 둘 수 있습니다.
- **내 조 / 4조 전체 보기** — 달력 한 칸에 4개 조의 근무가 색 배지로 나란히 보여서 친구 근무까지 한눈에 확인됩니다.
- **연차·반차·휴가·대체휴무·특근·근무변경·메모** — 날짜를 누르면 바텀시트가 열리고, 조를 고른 뒤 한 번에 추가/삭제할 수 있습니다. 휴무일에 나간 특근, 특근 뒤 받은 대체휴무도 같은 방식으로 기록됩니다.
- **잔여 연차 자동 계산** — 올해 총 연차를 넣으면 연차 1일, 반차 0.5일로 계산해 남은 일수를 보여줍니다.
- **링크 공유** — 설정과 연차·휴가·메모가 링크 안에 담겨 전달됩니다(서버 없음). 받은 사람은 "내 기기에 저장"으로 자기 기기에도 저장할 수 있습니다. 링크는 보낸 시점의 내용으로 고정되므로, 연차를 더 넣은 뒤에는 새 링크를 다시 보내면 됩니다.
- **캘린더(.ics) 내보내기** — 내 조의 향후 3개월 근무·연차를 아이폰 기본 캘린더에 넣을 수 있습니다.
- **홈 화면에 추가(PWA)** — 아이폰 Safari에서 `공유 → 홈 화면에 추가`하면 앱처럼 전체 화면으로 열립니다. 오프라인에서도 마지막 화면이 열립니다.

## 아이폰에서 앱처럼 쓰기

1. Safari로 위 주소를 엽니다. (카카오톡 인앱 브라우저에서는 안 될 수 있어요.)
2. 하단 **공유** 버튼 → **홈 화면에 추가** → **추가**.
3. 홈 화면의 "4조 근무표" 아이콘으로 바로 열립니다.

## 처음 한 번만 하는 설정

앱 오른쪽 위 ⚙️(설정)에서

1. **조 이름** — 1~4조를 내 조·친구 이름으로.
2. **내 조** — 내가 몇 조인지.
3. **기준 주** — 아무 주나 골라 그 주에 각 조가 어떤 근무였는지 지정 (예: 2026-11-16 주에 1조 오전, 2조 오후, 3조 야간, 4조 휴무).
4. **근무 요일** — 오전주·오후주·야간주마다 근무하는 요일을 5일/6일/7일 또는 요일별로 지정.
5. **순환 순서·총 연차** — 회사 규칙에 맞게.

저장하면 이후로는 앱을 열 때마다 오늘 내 근무와 이번 달 근무표가 바로 보입니다.

## 데이터는 어디에 있나요

- 근무표·연차·메모는 **이 기기의 브라우저 저장소(localStorage)** 에만 있습니다. 서버로 보내지 않습니다.
- 공유 링크에는 근무표 내용이 **URL 해시(`#s=...`)** 로 담깁니다. 링크를 아는 사람은 내용을 볼 수 있으니, 공개하고 싶지 않은 메모는 넣지 마세요.

```
app.js                근무 계산·달력·설정·공유·.ics

sw.js                 오프라인 캐시 (network-first)
icons/                앱 아이콘 (SVG·PNG, maskable 포함)
tools/make_icons.py   아이콘 생성 스크립트
```
